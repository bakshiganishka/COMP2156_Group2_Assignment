## 📌 Project Overview

This repository contains the group assignment for COMP2156 – DevOps for System Administration.  

The purpose of this project is to demonstrate practical understanding of:

- Git version control
- Branching strategies
- Pull request workflow
- Collaboration in a team environment
- Continuous Integration (CI) using GitHub Actions
- DevOps practices within the Software Development Life Cycle (SDLC)

Each group member created their own branch, contributed individual files, and merged their work into the main branch following proper Git workflow.
